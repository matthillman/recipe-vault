# Tasks

Use `tasks/` for multi-step initiatives (re-organization, standardization, audits, migrations).

- First add the work to `project/ROADMAP.md`, then create the task file if it needs a plan.
- Naming: `tasks/NNN-short-slug.md` (example: `tasks/001-standardize-recipe-template.md`)
- Start from: `tasks/000-sample.md`
- When complete: check off steps and add a short “Summary of Changes” section.
