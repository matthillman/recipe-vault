# Modernist

This folder is for modernist ingredients and techniques (hydrocolloids, emulsions, gels, foams, stabilization, etc.).

## What Goes Here

- Ingredient notes: what it is, typical dosages, how to hydrate, common failure modes.
- Technique notes: step-by-step protocols (with temps, order of operations, and “why”).
- Experiment logs: link to `notes/experiments/` when we run trials.

## Conventions

- Always record **brand/grade** (e.g., methylcellulose type, gelatin bloom) and **process** (shear, heat, rest).
- Prefer percentages by weight (e.g., `0.25% xanthan`) and specify base (total liquid vs total batch).
