# Clarification

Notes and protocols for getting juices/punches clear and **staying** clear (especially for batching, bottling, and nitro/carb service).

## Quick Decision Guide

Start by identifying what’s causing haze:

- **Pulp/solids**: start with settling + coarse filtration, then finer filtration.
- **Pectin haze (common in citrus, apple, many fruit juices)**: use **pectinase** before filtering.
- **Protein haze (tea, some juices, dairy-free punches)**: consider **bentonite** (bench test).
- **Emulsified oils (citrus peel oils, nut fats)**: remove oils first (cold crash + skim; absorbent paper; centrifuge).

Then choose a method based on equipment and how “neutral” the clarified liquid must taste:

- **Agar/gel clarification**: good general-purpose “lab” method; can soften acidity/aroma slightly.
- **Milk punch**: clarifies + rounds flavors (not neutral; adds milk character even when “clear”).
- **Enzyme + filtration**: best for keeping fruit character while preventing pectin haze.
- **Centrifuge**: fastest, least adulteration (if you have one), still benefits from enzymes for pectin-heavy juices.
